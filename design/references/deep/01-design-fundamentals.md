## Visual elements

Every composition is built from: point, line, plane (shape), texture, color, and space (negative space). Treat each as a deliberate choice:

- Use **lines/rules** to separate or organize, not decorate. A rule that separates nothing is noise.
- Use **shape consistency**: pick geometric or organic or hand-drawn per project and stay in that family (illustration, icons, buttons).
- Use **texture** only when it carries meaning (paper feel, depth cue); it taxes legibility.
- Treat **negative space as an element**: it groups, separates, and creates hierarchy before any border or background does.

## Design principles

Apply all of these; a composition fails when any is absent.

**Contrast** — make different things clearly different (size, weight, color, shape). If two elements differ by intent, the difference must be immediately visible; "almost the same" reads as a mistake. Never contrast everything with everything — contrast exists to direct the eye.

**Repetition** — repeat colors, type styles, spacing values, component patterns across the whole artifact. Repetition is what makes a set of screens/pages read as one system.

**Alignment** — every element aligns to at least one other element or to a grid line. Nothing floats arbitrarily. One dominant alignment axis per composition.

**Proximity** — spatial closeness encodes relationship. Items in a group sit closer to each other than to neighboring groups. This is the strongest, cheapest grouping device — use whitespace for grouping before boxes, borders or backgrounds.

**Balance** — distribute visual weight (size, density, color saturation, position) deliberately. Symmetric = formal, calm; asymmetric = dynamic. Imbalance without purpose reads as error.

**Emphasis (focal point)** — every view has exactly one dominant element; everything else supports it. Two focal points = none.

**White space** — add more than feels natural, then stop adding content. Dense layouts fail through missing hierarchy, not missing space.

**Unity with variety** — system consistency (unity) plus a few deliberate contrasts (variety). Total uniformity is boring; total variety is chaos.

## Gestalt grouping laws

The eye groups elements automatically; design must make the automatic grouping match the intended one.

| Law | Rule for use |
|---|---|
| Proximity | Space elements so spatial distance encodes logical relationship |
| Similarity | Same look (color/size/shape) = same meaning. Never style unrelated items identically |
| Closure | Incomplete shapes are read as complete — use for simple, cropped motifs |
| Continuity | Elements on a line are read as one group; align to create flow, avoid accidental lines |
| Figure/ground | Foreground/background must be unambiguous — check contrast and overlap |
| Common region | A shared box/background groups strongly — use sparingly (cards), it beats proximity |
| Uniform connectedness | Lines/arrows connect items into one unit — use for flows and relationships |

## Decision rules

```text
IF two elements look almost identical but serve different purposes
THEN make the difference explicit (contrast) or make them identical (repetition).

IF an element aligns to nothing
THEN align it to the grid or to a sibling; delete "eyeballed" offsets.

IF grouping is done with boxes/borders/backgrounds
THEN first try grouping with whitespace alone (proximity); keep the box only if it aids scanning.

IF a composition feels cluttered
THEN reduce the number of distinct type styles and colors before removing content.

IF everything on the page shouts (bold, color, size)
THEN keep one focal element loud and quiet everything else.

IF a pattern is used once (color, icon, spacing value)
THEN expect to reuse it everywhere; define it as a token.
```
