# Example research report (placeholder — US-admissions style topics follow the same skeleton)

The previous kit shipped long sample reports in Russian. This Komplekt build is English-first for skill instructions.

Use this skill’s own structure section as the template. For a worked example, write a short report on a real question using:

1. Title + date + decision the report supports  
2. Executive summary (≤1 page)  
3. Evidence sections with source levels A–E  
4. Contradicting evidence  
5. What would change the conclusion  
6. Recommendation + sources  

Do not pad with filler. Prefer primary sources and explicit uncertainty.
