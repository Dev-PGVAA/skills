# Contextual links

Read the current passage and actual candidate notes. Resolve aliases and duplicated basenames before selecting targets. Match useful relationships: prerequisite, definition, evidence, example, decision rationale, contradiction, or next step. A shared keyword alone is insufficient.

Propose only as many links as have a reader benefit; zero is valid. For each, give the source passage or insertion point, exact target and syntax, relationship, and a concise suggested sentence if needed. For inbound suggestions inspect the source note too. When only titles are accessible, label candidates as unverified rather than describing their unseen content.

Respect existing wikilinks, Markdown relative paths, heading links, block references, and display aliases. Verify the target anchor when supplied. Do not create stubs unless requested. For duplicate candidates, explain the overlapping and distinct material instead of automatically adding mutual links. A short note can still merit one strong link without being expanded into an essay.

If edits are authorized, preserve surrounding prose and metadata, apply only supported links, and recheck that the saved target resolves. A suggestion-only request stays read-only.
