# Komplekt

14 agent skills. No more. Strengthened design, humanizer, product (contrarian), deep-research (falsify), code-quality, skill-finder. Added graph-surgeon.

All instructional skill text is **English** (better model following), except `russian-master`, which stays Russian by design (language norms / EGE).

## Install

Copy each skill folder into `~/.agents/skills/<name>/` (Claude Code, Codex, Cursor, OpenCode — wherever your agent looks).
