# Частотные ошибки

Формат: `ошибка → норма → правило одним предложением`.

## Грамматика и лексика
- `ложить → класть`: норма — только `класть`, `ложить` — просторечие.
- `звОнит → звонИт`: у глагола `звонить` ударение на окончании — `звонИшь, звонИт, звонИм`.
- `ихний → их`: формы `ихний` у местоимения `их` нет — это просторечие.
- `ляжь сюда → ляг сюда`: повелительное от `лечь` — `ляг`, без мягкого знака.
- `ехай быстрее → поезжай быстрее`: повелительное от `ехать` — `поезжай`.
- `более лучше → лучше / более хороший`: нельзя соединять простую и составную сравнительную степень.
- `более интереснее → более интересный / интереснее`: двойной показатель сравнения — ошибка.
- `кто пришёл? они → он`: при подлежащем `кто` ответ согласуется в единственном числе мужского рода.
- `много народу пришли → пришло`: при количественно-именном подлежащем сказуемое — в единственном числе среднего рода.

## Управление
- `по приезду в город → по приезде в город`: предлог `по` в значении «после» требует предложного падежа (`по приезде, по прибытии, по окончании`).
- `согласно приказа → согласно приказу`: предлог `согласно` управляет дательным падежом.
- `вопреки прогноза → вопреки прогнозу`: предлог `вопреки` требует дательного падежа.
- `благодаря старания → благодаря стараниям`: предлог `благодаря` требует дательного падежа.
- `оплатить за проезд → оплатить проезд / заплатить за проезд`: `оплатить` — без предлога, `заплатить` — с `за`.
- `в городе Москва → в городе Москве`: родовое слово и название города согласуются в падеже.
- `скучаю по вас / по вам`: допустимы обе формы — `по вас` (традиционная строгая норма) и `по вам`; при строгой проверке сверься со словарём.

## Числительные
- `обеих мальчиков → обоих мальчиков`: `оба` — мужской и средний род, `обе` — женский, во всех падежах.
- `двое девушек → две девушки`: собирательные числительные не сочетаются с существительными женского рода.
- `пятистами рублями → пятьюстами рублями`: творительный падеж от `пятьсот` — `пятьюстами`.
- `около пятиста человек → около пятисот человек`: родительный падеж — `пятисот`.

## Произношение
- `тортЫ → тОрты`: только ударение на первый слог.
- `красивЕе → красИвее`: только `красИвее`.
- `свеклА → свЁкла`: только `свЁкла`.
- `жалюзИ`: ударение на последний слог, не `жАлюзи`.

## Пунктуация (частое в сочинениях)
- Если `что` присоединяет придаточное — запятая перед ним обязательна: `Я знаю, что он придёт`.
- `Однако` в начале предложения — союз, запятой не отделяется: `Однако он пришёл`; в середине чаще вводное слово, обособляется: `Он, однако, пришёл`.
- Тире перед `это`, когда подлежащее и сказуемое — имена в именительном падеже: `Честность — это выбор, а не настроение`.
- Не переноси эти правила «по аналогии» на устойчивые сочетания и частицы — проверяй конструкцию целиком.

## Пять частых причин потери баллов на ЕГЭ
Без выдуманных цифр, по характеру потерь. К каждой — как защищаться.
1. Невнимательное чтение задания: пропускают «укажите все цифры», «в каком предложении».
   Защита: перед записью ответа перечитать вопрос и подчеркнуть в нём условие.
2. Угадывание по словам-маркерам: увидел `который` — ставит запятую без разбора конструкции.
   Защита: к каждому ответу называть правило, по которому поставлен знак.
3. Незнание формулировок критериев сочинения: пишут пересказ вместо комментария, не опознают позицию автора.
   Защита: разобрать критерии заранее и сверять свой черновик с ними по пунктам.
4. Объём и абзацное деление: эксперт не находит нужный элемент структуры — теряются баллы.
   Защита: каждый смысловой блок (тезис, аргумент, вывод) — отдельный абзац с красной строки.
5. Невыполнение инструкции по записи ответа: не та форма в бланке, ответ не в той строке, лишние символы.
   Защита: инструкции бланков читать до экзамена; на экзамене записывать ответ ровно в заданном формате.

## Как использовать файл
- За одну сессию отрабатывай 5–7 ошибок, не весь список: перегруз отменяет эффект.
- Каждую ошибку показывай минимальной парой `ошибка → норма`, см. `teaching/explanations.md`.
- Встретил новую частотную ошибку — добавляй строкой того же формата, только после проверки нормы по словарю.
- Перед экзаменом прогоняй список как чек-лист: ученик читает левую часть, называет норму вслух.
