# Версия экзамена: сначала год и статус

Проверка доступных официальных страниц: **12.09.2026**. [Страница ФИПИ](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory) сейчас содержит **проекты ЕГЭ-2027** и архив комплекта ЕГЭ-2026. Проект не равен утверждённым документам. Год сдачи пользователя имеет приоритет над календарным годом; если он неизвестен и влияет на балл, уточни его, продолжая доступную языковую проверку.

## Как выбрать документы

1. Выбери год, затем проверь заголовок, статус и дату конкретного файла. Не доверяй одному имени файла или поисковому сниппету.
2. Для формата и оценивания прочитай демоверсию и спецификацию; для перечней — соответствующие материалы ФИПИ; для подсчёта ошибок — методические материалы предметной комиссии.
3. Сохрани в рабочей проверке год, статус, название документа и URL/страницу. Если файл не удалось прочитать, не называй его проверенным.
4. Если доступен только проект, прямо обозначь предварительность оценки и назови используемую версию. Не смешивай таблицы разных лет.

## Проверенный ориентир ЕГЭ-2026

По [методическим рекомендациям ФИПИ для подготовки в 2026 году](https://doc.fipi.ru/navigator-podgotovki/navigator-ege/MR_rus_yaz_ege_2026.pdf), с. 5–9: 27 заданий; максимум 50 первичных баллов; задания 8 и 22 допускают частичный балл, большинство кратких ответов — нет. В сочинении меньше 150 слов означает ноль по всем десяти критериям. Особую шкалу для 100–149 слов применять нельзя. При значительной доле исходного текста действуют отдельные правила подсчёта собственного объёма — прочитай с. 6–7.

К5 в комплекте 2026: 2 балла без логических ошибок, 1 при одной-двух, 0 при трёх и более. Для аргумента К3 уточнено требование нового фактического материала. [Официальные изменения 2026](https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2026/Izmeneniya_KIM_EGE_2026.pdf).

Это опорный снимок, **не полная инструкция по выставлению баллов** и не подтверждение правил 2027/2028. Полная демоверсия из архива в этом обновлении не извлечена; подробные пограничные условия критериев нужно проверять при конкретной работе.
