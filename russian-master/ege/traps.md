# Частые ловушки при решении

Проверяй по полной формулировке и материалам нужного года. Эта памятка не задаёт формат конкретного задания.

| Ловушка | Проверка |
|---|---|
| Номер принят за неизменное условие | Прочитай год и текст задания; используй [tasks.md](tasks.md) как ориентир |
| Ряд исключён «на слух» | Назови неверный элемент и правило; проверь остальные варианты |
| Одинаковые буквы требуют одного правила | Сравни результат, не названия правил |
| Словарное слово исключено из правильного ряда | Словарная проверка тоже даёт нормативное написание |
| Привычное ударение выдано за норму | Проверь точную форму; `понялА`, `ободрЁнный`, `ободренА` |
| Верная форма кажется ошибочной | Не исправляй `пятьюстами`, `ляг`, `поезжай`, `полощет` без основания |
| Гласная чередующегося корня проверена ударением | Сначала установи значение и принадлежность к чередованию |
| Приставка вы- скрывает ударное окончание | Проверь исходный глагол: `спать — спят`, `выспаться — выспятся` |
| Любое зависимое слово меняет написание НЕ | Различай причастие, прилагательное и слова степени |
| Краткое прилагательное смешано с причастием | `дети воспитаны родителями` и `дети вежливы и воспитанны` |
| Запятая поставлена перед каждым и | Проверь, что именно соединяет каждый союз и нет ли парных групп |
| Слово можно убрать, значит оно вводное | Изъятие не доказывает вводность; установи функцию |
| После но перед придаточным якобы никогда нет запятой | На стыке союзов решают структура, возможность изъятия и продолжение то/так |
| Перед который/где всегда ставится знак | Граница может быть раньше: `дом, у ворот которого...` |
| Любой повтор звука назван выразительным средством | Докажи функцию повтора и соотнеси с терминами задания |
| Содержание текста заменено житейской вероятностью | Найди подтверждающий фрагмент, не дополняй автора |
| Названа связь примеров без пояснения | Объясни, что именно противопоставлено/дополнено и зачем это для позиции автора |
| Готовый шаблон гарантирует высокий балл | Проверяй содержание каждого критерия и версию шкалы |
| Сочинение оценено без исходного текста | Пометь недоступные критерии; не выдумывай общую сумму |

Подробные языковые условия — в `knowledge/`; спорный случай требует нормативного источника, а не новой категоричной мнемоники.
