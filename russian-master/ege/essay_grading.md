# Сочинение ЕГЭ: критерии 2026 (К1–К10, максимум 22 балла)

Критерии приведены по комплекту 2026 года (см. `current_exam.md`). Не применяй шкалу К1–К12 прошлых лет и не смешивай с итоговым сочинением (там «зачёт/незачёт», минимум 250 слов — см. `final_essay/criteria.md`).

## Правила объёма и подсчёта слов

- Основные нормы разработаны для работ объёмом **от 150 слов**.
- **149 слов и меньше** — по критериям К1–К6 выставляется 0.
- **100–149 слов** — работа проверяется, но по каждому критерию грамотности К7–К10 максимум **2 балла** (ужесточённый допуск ошибок).
- **99 слов и меньше** — задание не засчитывается вовсе (0 за всё задание).
- Подсчёт слов: «всё-таки» — одно слово, «всё же» — два; инициалы с фамилией — одно слово («М. Ю. Лермонтов»), полное имя — три; цифры и символы не учитываются («5 лет» — одно слово).

| № | Критерий | Баллы |
|---|---|---|
| К1 | Отражение позиции автора (рассказчика) по указанной проблеме исходного текста | 1 |
| К2 | Комментарий к позиции автора по указанной проблеме | 3 |

| К10 | Соблюдение речевых норм | 3 |

## Расшифровка содержания

**К1 (1/0).** Позиция автора понята и передана верно, без искажений. 0 — позиция не отражена, понята ошибочно или подменена пересказом.

**К2 (3/2/1/0).**
- 3: приведены **два** примера-иллюстрации, важных для понимания проблемы; к каждому дано **пояснение**; указана **смысловая связь** между примерами и дано её пояснение.
- 2: два примера с пояснениями, но связь не указана / указана неверно / не пояснена.
- 1: один пример-иллюстрация с пояснением.
- 0: пример без пояснения не засчитывается; комментарий без опоры на исходный текст; пересказ вместо комментария; цитирование крупного фрагмента текста.

**К3 (2/1/0).**
- 2: отношение сформулировано, обосновано и подтверждено **примером-аргументом** из читательского, историко-культурного или жизненного опыта. Комиксы, аниме, манга, фанфики, компьютерные игры не учитываются.
- 1: обоснование есть, примера-аргумента нет; или пример есть, но отношение к позиции автора не сформулировано.

**К4 (1/0).** Нет фактических ошибок: в передаче фактов исходного текста, в фоновых сведениях (имена, даты, названия, авторы, сюжеты).

**К5 (2/1/0).** Логичность речи: 2 — логических ошибок нет; 1 — одна-две; 0 — три и более. Логические ошибки: нарушение последовательности изложения, неоправданные повторы, противоречия между частями, «выпадение» аргумента из тезиса, абзац без связи с предыдущим.

**К6 (1/0).** Этические нормы: нет грубости, оценок, унижающих достоинство, этически некорректных формулировок.

**К7–К10 (единая шкала 3/2/1/0).** 3 — ошибок нет; 2 — одна-две; 1 — три-четыре; 0 — пять и более. Учитываются только ошибки соответствующего типа (орфографические / пунктуационные / грамматические / речевые).

## Процедура проверки чужой работы

1. Убедись, что есть полный исходный текст. Без него К1, К2, К4 полноценно не проверяются — честно скажи об этом.
2. Прочитай сочинение целиком; выпиши все ошибки с классификацией (см. `SKILL.md`, типы ошибок).
3. Пройди критерии по порядку: К1 → К2 → К3 → К4 → К5 → К6 → К7–К10. Для каждого балла указывай доказательство (цитату из работы).
4. Посчитай сумму; сравни с максимумом 22.
5. Дай три конкретных шага доработки: что добавить/убрать/исправить, чтобы поднять самые «дешёвые» для ученика баллы (обычно К2 — связь примеров; К3 — пример-аргумент; К7/К8 — вычитка).

Не завышай и не занижай «из вежливости»: оценка без доказательств по каждому критерию не выставляется.
