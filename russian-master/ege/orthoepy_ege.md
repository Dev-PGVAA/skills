# Ударения: учебный набор для тренировки

Это сокращённая памятка, **не полный и не заверенный словник ФИПИ**. При решении задания нужного года сверяй конкретное слово и форму с официальными материалами; варианты общей литературной нормы проверяй по профильному словарю. Формат ответа задаёт само задание: не предполагай, что в каждом варианте обязательно два слова или несколько рядов.

## Опорные слова

- Существительные: `аэропОрты, бАнты, бухгАлтеры, вероисповЕдание, граждАнство, дефИс, диспансЕр, договОр, жалюзИ, каталОг, квартАл, киломЕтр, корЫсть, крАны, мусоропровОд, намЕрение, недУг, нЕнависть, нОвости, портфЕль, свЁкла, сирОты, срЕдства, столЯр, тОрты, цемЕнт, шАрфы, шофЁр, экспЕрт`.
- Прилагательные: `красИвее, кУхонный, оптОвый, слИвовый`. Различай значение: `языковАя норма` и `языкОвая колбаса`.
- Глаголы: `баловАть, балУет, звонИт, включИт, дозвонИтся, клАла, клЕит, облегчИть, ободрИт, понялА, углубИть, укрепИт, чЕрпать`.
- Причастия и деепричастия: `углублЁнный, ободрЁнный, ободренА, нАчатый, прожИвший, начАв, отдАв, поднЯв, создАв`.

Семьи форм полезнее ложной общей формулы: `зАнял — занялА — зАняли`; `нАчал — началА — нАчали`; `пОнял — понялА — пОняло`.

## Тренировка

1. Предложи небольшую смешанную порцию слов без выделенного ударения. Сначала дождись попытки, если пользователь просит практику.
2. Разбери ошибки с нормой и источником для спорного случая; не закрепляй неверное ударение рифмой.
3. Повтори ошибочные формы в новом порядке вместе с уже верными; затем проверь их в предложении.
4. На следующем доступном занятии проверь воспроизведение без подсказки. Не объявляй одно правильное чтение доказательством устойчивого усвоения.

Пары `пОняла` и `обОдренный/обОдрена` из прежней базы были ошибочны. Исправления подтверждены словарными данными; см. [source-checks.md](../references/source-checks.md).
