# Словник орфоэпических норм для ЕГЭ (задание 4)

Ядро высокой частоты официального перечня (словарик в кодификаторе ФИПИ). Полный актуальный список — только в кодификаторе текущего года; при сомнении и для редких слов сверяйся с ним.

Формат задания: найти ряды, где во всех словах верно выделен ударный звук/слог (точную формулировку см. в демоверсии текущего года). Ответ считается верным только по строгой норме.

## Существительные

`агЕнт, алфавИт, апострОф, аэропОрты, бАнты, бОроды, бухгАлтеры, вЕрба, вероисповЕдание, гЕнезис, дешевИзна, дефИс, диспансЕр, договОр, еретИк, жалюзИ, знАчимость, Иконопись, Искра, каталОг, квартАл, киловАт, киломЕтр, коклЮш, корЫсть, крАны, крЕсла, ломОта, мусоропровОд, намЕрение, нарОст, недУг, нЕнависть, нОвости, нОгти, нОворождЁнный, обострЕние, пЕтля, пОручни, портфЕль, простЫня, свЁкла, сирОты, слИвки, срЕдства, столЯр, тОрты, тОтчас, цемЕнт, цЕнтнер, хвОя, шАрфы, шофЁр, экспЕрт, нефтепровОд, газопровОд`.

Пары «частая ошибка → норма»: `звОнит → звонИт`, `дОговор → договОр`, `кАталог → каталОг`, `средствА → срЕдства`, `щАвель → щавЕль`, `свеклА → свЁкла`, `квАртал → квартАл`, `мусоропрОвод → мусоропровОд`.

## Прилагательные

`знАчимый, красИвее, красИвейший, кУхонный, лАвровый, оптОвый, прожОрливый, слИвовый, балОванный, нОворождЁнный`.

Различай: `языковАя` (система, норма) — `языкОвая` (колбаса).

## Глаголы

Формы прошедшего времени ж. р. с ударением на окончании:
`бралА, бралАсь, взялА, взялАсь, ворвАлась, гналА, гналАсь, добралА, добралАсь, дождалАсь, ждалА, звалА, лилА, лилАсь, налилА, нарвалА, обнялА, позвалА, полилА, послАла, сорвалА, снялА, снялАсь, создалА`.

Пары с ударением на приставке (кроме ж. р.):
`зАдал — задалА — зАдали; зАнял — занялА — зАняли; нАчал — началА — нАчали; зАпер — запертА; прИбыл — прибЫла — прибЫло — прибЫли; снЯл — снялА`.

Прочие глаголы:
`балОвать, балУюсь, балУет, дозвонИтся, включИт, включИм, клАла, клЕит, клЕят, кровоточИть, лгалА, облегчИть, ободрИт, пОняла, углубИть, укрепИт, чЕрпать`.

## Причастия и деепричастия

`зАперт, запертА, зАперто, нАчатый, прожИвший, Умерший, углублЁнный, балУясь, взЯвшись, начАв, начАвшись, отдАв, поднЯв, поднЯвшись, прибЫв, создАв`.

Пары «привычное ударение → норма» (частые ловушки): `дешевизнА → дешевИзна`, `углУбленный → углублЁнный`, `обОдрит → ободрИт`, `кухОнный → кУхонный`, `нЕдуг → недУг`, `пОдняв → поднЯв`. Родственные формы с другим ударением: глагол `ободрИт`, но причастия `обОдренный, обОдрена`.

## Наречия

`вкратцЕ, воврЕмя, дОбела, доверхУ, дОнизу, донЕльзя, дОтемнА, дОсыта, зАвидно, зАгодя, зАтемно, ИздавнА, исстАри, надОлго, навЕрх, накОнец, ненАдолго, тОтчас`.

## Как тренировать задание 4

1. Проговаривай слово целиком с выделенным ударением; списки читай вслух.
2. Группируй по «семьям»: формы одного глагола (`зАнял — занялА — зАняли`) учатся одной карточкой.
3. Держи отдельный список «мои ошибочные слова» и повторяй только его.
4. В самом задании сначала проверяй каждое слово по памяти, затем ищи ряд, где оба слова верны; не выбирай ряд «по одному знакомому слову».
