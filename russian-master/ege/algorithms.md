# Алгоритмы решения заданий ЕГЭ

Пошаговые цепочки. Правила — в `knowledge/`, карта заданий — в `tasks.md`.

## Протокол решения варианта (до начала и перед сдачей)

1. Формулировка задания задаёт формат ответа — прочитай её раньше, чем начнёшь решать.
2. Многовариантные задания: все ряды проверяются полностью, до последнего слова. Ряд отбрасывается только с доказанной ошибкой — «первое слово показалось неправильным» не основание. Недобор верных вариантов и лишний неверный — одинаково обнуляют ответ.
3. Ответ выписывай из черновой таблицы проверки, а не по памяти о разборе; в заданиях на соответствие число цифр равно числу позиций.
4. Словарные формы, ударения, паронимы — только по словникам скилла, при отсутствии слова в словнике помечай неуверенность.

## Задание 1 (заметка/информация)

1. Прочитай источник (таблицу + текст) полностью.
2. Выпиши: о чём/о ком, главное обстоятельство, главный вывод.
3. Отбрось детали, примеры, повторы.
4. Перескажи своими словами, ничего не добавляя от себя.
5. Проверь: каждое утверждение подтверждается источником?

## Задание 2 (средства связи)

1. Возьми предложение, для которого ищешь связь.
2. Найди в нём слово, отсылающее назад (местоимение, союз, повтор, синоним).
3. Назови тип средства точно и проверь, что оно связывает именно с предыдущим предложением.

## Задания 9–15 (орфография)

1. Для каждой строки определи орфограмму: корень / приставка / суффикс / окончание / НЕ-НИ / слитно-раздельно / Н-НН.
2. Примени правило из `knowledge/01_orthography.md` к каждому слову.
3. Для каждого ряда выпиши буквы всех слов подряд и сравни (`заст..лать — заст..лить → И, Е — ряд неверен`). Ряд верен, только если все буквы совпали и ни одно слово не словарное исключение.
4. Ищи строку, где ВСЕ слова соответствуют одному правилу и написаны верно.
5. Проверь исключения до выбора ответа; словарные слова сверяй по спискам, не по памяти.

## Задания 16–21 (пунктуация)

1. Прочитай предложение, подчёркивая грамматические основы.
2. Пронумеруй места, отмеченные цифрами, и для каждого реши: что здесь стоит (оборот, вводное, однородные, граница частей)?
3. Назови основание знака для каждой цифры. Нет основания — нет знака.
4. Для задания 21 пройди все цифры последовательно, начиная с границ сложного предложения.

## Задание 22 (средства выразительности)

1. Прочитай термины в таблице; вспомни определение каждого (`knowledge/08_speech_style.md`).
2. Для каждого фрагмента определи приём по формальному признаку, не по настроению: повтор в начале смежных строк — анафора, в конце — эпифора; повторяются гласные — ассонанс, согласные — аллитерация; глагольный ряд без союзов — бессоюзие; вопрос без ожидания ответа — риторический вопрос; обращение к неодушевлённому или отсутствующему — риторическое обращение; переносное значение по сходству — метафора, по смежности — метонимия.
3. Соотнеси термин и пример; проверь ловушки (эпитет vs определение, метафора vs сравнение, метонимия vs синекдоха).
4. Перед записью ответа пересчитай: цифр столько, сколько позиций А–Д.

## Задание 25 (лексический анализ текста)

1. Прочитай формулировку: что искать (синоним, антоним, фразеологизм, переносное значение, разговорное слово...).
2. Ищи по критерию, а не по «похожести»: синонимы заменяют друг друга в этом контексте; антонимы противопоставлены по одному признаку.
3. Выпиши слово точно в той форме, что в тексте (если формат требует слово, а не номер предложения).

## Задание 26 (типы речи)

1. Для каждого фрагмента спроси: что делает текст — сообщает события во времени (повествование), перечисляет признаки одновременно (описание), доказывает мысль (рассуждение)?
2. Проверь маркеры: повествование — глаголы движения/последовательности; описание — определения, назывные предложения; рассуждение — тезис, аргументы, вывод.
3. Не решай по одному слову — смотри функцию фрагмента целиком.

## Задание 27 (сочинение): план написания за 60 минут

1. Прочитай текст два раза; на втором выпиши: проблему из задания, позицию автора, 2 эпизода-примера с номерами предложений.
2. Сформулируй позицию автора одним предложением (К1).
3. Набросай пояснения к двум примерам и тип связи между ними (К2).
4. Реши своё отношение и подбери пример-аргумент (К3).
5. Напиши по конструктору `ege/essay.md`: 4–7 абзацев, 150–250 слов (оптимально 200+).
6. Вычитка: орфография → пунктуация → грамматика → речь (К7–К10: одна-две ошибки уже снимают балл).
