# Сочинение ЕГЭ (задание 27): конструктор

Формат 2025–2026: проблема текста уже сформулирована в задании — отдельно её «зарабатывать» баллом не нужно. Сочинение = отражение позиции автора + комментарий с опорой на текст + своё отношение с аргументом. Объём: минимум 150 слов (меньше — 0 по всем критериям), комфортный ориентир 180–250.

Строится не по монолитному шаблону, а по функциям абзацев. Канцелярский штамп («Автор данного текста поднимает злободневную проблему...») не используй.

## Эталонная структура (по реальному сочинению 22/22, ЕГЭ-2025)

| Абзац | Функция | Объём |
|---|---|---|
| 1 | Проблема из задания + выход на текст | 1–2 предложения |
| 2 | Позиция автора (К1) | 1–2 предложения |
| 3 | Пример-иллюстрация 1 + пояснение | 3–5 предложений |
| 4 | Пример-иллюстрация 2 + пояснение | 3–5 предложений |
| 5 | Смысловая связь между примерами | 2–3 предложения |
| 6 | Своё отношение + обоснование + пример-аргумент (К3) | 4–6 предложений |
| 7 | Заключение-обобщение | 1–2 предложения |

Связь можно вынести в отдельный мини-абзац — эксперты это одобряют: она видна мгновенно, и К2 не теряется. Заключение формально не обязательно (балл за его отсутствие не снимается), но 1–2 предложения обобщения оставляй.

## Функция 1. Выход на проблему и позиция автора

- От вопроса задания к тексту: `Над этим вопросом размышляет (автор) в предложенном для анализа тексте.`
- Позиция автора — сразу, коротко: `Автор считает, что ...` / `Позиция автора ясна: ...` / `Автор убеждён: ...`

Чего избегать: пересказа начала текста на 5 предложений; позиции автора в форме вопроса; смешения автора и рассказчика (в художественном тексте это разные лица — ошибка по К1).

## Функция 2. Комментарий (К2, до 3 баллов)

Структура каждого примера: подводка → пример (эпизод, можно цитату до ~10 слов) → пояснение.

- Подводки: `Раскрывая проблемный вопрос, автор приводит ...` / `Продолжая раскрывать проблемный вопрос, автор повествует о ...`
- Пояснение — не пересказ, а ответ на вопрос «что автор делает этим эпизодом»: `Так автор показывает, что ...` / `Этот эпизод нужен автору, чтобы ...`
- Связь (называй явно): `Примеры противопоставлены: сначала ..., затем ...` / `Эти примеры дополняют друг друга: ...`

Типы смысловой связи (методичка ФИПИ — называй и поясняй одну): противопоставление, сопоставление, аналогия, дополнение, причина, следствие, уступка, цель, условие, конкретизация, пояснение, выделение, обобщение, вывод, подтверждение, определение, объяснение.

Чего избегать: примера без пояснения (не засчитывается); цитирования больших фрагментов; пересказа вместо анализа; двух примеров из одного эпизода, различающихся только формулировкой; необязательных слов-паразитов («наверное», «скорее всего») в комментариях.

## Функция 3. Своё отношение и обоснование (К3, до 2 баллов)

Сформулировать отношение (согласие/несогласие/частичное согласие), обосновать и привести пример-аргумент из читательского, историко-культурного или жизненного опыта. Комиксы, аниме, манга, фанфики, компьютерные игры не учитываются.

- `Я согласен с позицией автора. Действительно, ...`
- Частичное согласие — сильный ход при уверенности: `В целом соглашаясь с автором, уточню: ...`
- Можно не соглашаться — за несогласие баллы не снимают, снимают за необоснованность.
- Аргумент = конкретный случай (произведение + поступок героя + следствие), не название произведения и не лозунг: `Своё мнение аргументирую примером из романа ...`

Требования к аргументу: чёткость и конкретность важнее «солидности» — жизненный пример засчитывается; о прочитанном не фантазируй.

## Функция 4. Заключение

Возврат к проблеме, обобщение без новых мыслей: `В заключение хочу сказать, что ... — в этом и состоит главная мысль текста.`

## Тактика работы на экзамене (по рекомендациям экспертов)

1. Сначала тезисный план: позиция автора, пример 1, пример 2, связь, мнение + аргумент. Пять строк — потом пишешь по ним.
2. Построение комментария начинай со связи: реши, как два примера соотносятся, — тогда сразу видно, какие эпизоды брать.
3. Не понял текст — составь план-пересказ: кто действует, что происходит, чем кончается. По плану позиция автора обычно находится.
4. Сочинение не обязано быть идеальным по стилю — оно обязано содержать все пункты анализа. Простой, но полный текст выигрывает у красивого, но с пропущенной связью.
5. Речевые ошибки («который» три раза подряд, «автор показывает» пять раз) — ловятся только перечитыванием вслух.

## Проверка перед сдачей

1. Проблема из задания перефразирована? Позиция автора — одним ясным предложением?
2. Два примера? У каждого пояснение? Связь названа и пояснена?
3. Отношение + обоснование + конкретный пример-аргумент?
4. Абзацы: 4–7, каждый выполняет одну функцию?
5. Объём от 150 слов; факты текста не искажены; нет этических нарушений.
6. Финальная вычитка: орфография, пунктуация, грамматика (по 3 балла за каждую группу — одна-две ошибки уже снимают балл).
