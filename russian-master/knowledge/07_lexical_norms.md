# Лексические нормы: паронимы, сочетаемость, плеоназм (задания 5 и 6)

## Задание 5: паронимы

Паронимы — близкие по звучанию, но разные по значению слова. Решай через точное значение, не «по звучанию». Надёжное ядро официального словарика ФИПИ:

- `абонемент` (право пользования) / `абонент` (тот, кто пользуется)
- `адресат` (получатель) / `адресант` (отправитель)
- `бережный` (заботливый) / `бережливый` (экономный)
- `дипломат` (должность) / `дипломант` (лауреат)
- `дождевой` (паводок) / `дождливый` (день, погода)
- `дружеский` (относящийся к другу) / `дружественный` (о странах, отношениях)
- `жизненный` (важный, бытовой) / `житейский` (повседневный)
- `значение` (смысл) / `значимость` (важность)
- `командированный` (человек) / `командировочный` (удостоверение)
- `ледовой` (патруль, арена) / `ледяной` (ветер, взгляд)
- `надеть` (что-то на себя) / `одеть` (кого-то)
- `отличать` (что от чего: отличить близнецов друг от друга, подделку от оригинала) / `различать` (что: различать в темноте, оттенки, цвета)
- `невежа` (грубиян) / `невежда` (необразованный)
- `органический` (химический, природный) / `органичный` (цельный, естественный)
- `отличать` (признаки различия) / `различать` (выделить среди других)
- `памятный` (о памяти события) / `памятливый` (обладающий хорошей памятью)
- `практический` (относящийся к практике) / `практичный` (выгодный, удобный)
- `представить` (показать, предъявить) / `предоставить` (дать право)
- `скрытый` (неявный) / `скрытный` (неоткровенный)
- `сытный` (питательный) / `сытый` (не голодный)
- `технический` (о технике) / `техничный` (мастерски выполненный)
- `удачный` (успешный) / `удачливый` (везучий человек)
- `хозяйственный` (относящийся к хозяйству) / `хозяйский` (как хозяин)
- `эстетический` (область эстетики) / `эстетичный` (красивый)
- `эффективный` (дающий эффект) / `эффектный` (производящий впечатление)
- `экономический` (относящийся к экономике) / `экономичный` (недорогой) / `экономный` (бережливый)
- `этический` (область этики) / `этичный` (соответствующий этике)
- `исторический` (относящийся к истории) / `историчный` (соответствующий эпохе)
- `опечатка` (в тексте) / `отпечаток` (след)
- `доходный` (приносящий доход) / `доходчивый` (понятный)
- `гигиенический` (относящийся к гигиене) / `гигиеничный` (чистый)

## Задание 6: сочетаемость, тавтология, плеоназм

Нарушение лексической сочетаемости (контаминация):
- `играть значение` → `играть роль / иметь значение`
- `одержать успех` → `одержать победу / добиться успеха`
- `повысить кругозор` → `расширить кругозор`
- `произвести внимание` → `обратить внимание / проявить внимание`
- `причинить радость` → `доставить радость` (но: `причинить вред`)
- `повысить внимание` → `привлечь внимание; повысить интерес`

Плеоназм (лишнее по смыслу слово):
- `памятный сувенир, прейскурант цен, период времени, главная суть, первая премьера, биография жизни, свободная вакансия, народный фольклор`
- `уникальное неповторимое зрелище` — достаточно одного из двух определений.

Тавтология (неоправданный повтор корня/слова):
- `спросить вопрос, рассказать рассказ, приблизиться ближе, в августе месяце, уровень повышается выше`.

## Как решать

1. Прочитай предложение и найди слово, которое «спотыкается».
2. Определи тип: неверное слово (пароним), несочетающиеся слова (контаминация), лишнее слово (плеоназм), повтор корня (тавтология).
3. Предложи замену с сохранением смысла — и проверь, что замена не ломает грамматику.
