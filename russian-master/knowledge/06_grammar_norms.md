# Грамматические нормы и ошибки (задание 8)

Задание: соотнеси тип ошибки с предложением (5 типов, 2 балла). Решается не «чутьём», а поиском маркера. Таблица «маркер → тип ошибки → как исправить».

| Маркер в предложении | Тип ошибки | Исправление |
|---|---|---|
| `все, кто...` + не тот глагол | Нарушение связи подлежащего и сказуемого | `Все, кто пришёл (не пришли),...`; `кто` — ед. ч., `все` — мн. ч. |
| `большинство + мн. ч.` | Нарушение согласования | `Большинство учеников справилось (не справились)` |
| `подъезжая к станции, у меня...` | Деепричастный оборот при не том субъекте | Действие оборота и сказуемого — один субъект: `Когда я подъезжал к станции, у меня слетела шляпа` |
| причастие + НЕ согласовано или разорвано | Причастный оборот | `ошибки, допущенные нами (не «допущенные ошибки нами»)` |
| два однородных требуют разных падежей | Управление при однородных членах | `любить и восхищаться природой` — ошибка: `любить природу и восхищаться ею` |
| соединены вид и родовое понятие | Логическая ошибка однородности | `яблоки, фрукты, апельсины` — ошибка; убрать родовое или видовое |
| разные времена/виды в ряду | Видо-временная соотнесённость | `Он приходит и сказал` — ошибка |
| `согласно приказа, благодаря решению (род.)` | Управление предлога | `согласно приказу, благодаря решению, вопреки прогнозу` — только дат. падеж |
| `по приезду, по окончанию школы` | Падеж после предлога «по» в знач. «после» | `по приезде, по окончании, по прибытии, по возвращении` — предложный падеж |
| `Он сказал, что я приду` | Смешение прямой и косвенной речи | `Он сказал, что придёт` |
| `вопрос, что поднялся...` | Неправильное союзное слово | `вопрос, который поднялся`; союз и союзное слово выбираются по их роли |
| `если... но, не только... а также` | Неверное парное сочетание союзов | `если... то; не только... но и; как... так и` |
| `двое студенток` | Числительные с одушевл. | `две студентки` (см. `04_morphology.md`) |
| придаточное далеко от слова | Построение СПП | Ставь `который` сразу после определяемого слова |

## Управление: надежный минимум

- `благодаря, согласно, вопреки, навстречу, подобно` + дат. падеж.
- `по` в значении «после» + предл. падеж: `по завершении, по истечении, по предъявлении`.
- `оплатить проезд` (без `за`) / `заплатить за проезд`; `отчет о работе / отчитаться за работу`.
- `скучать по вас и по вам` — вариантная норма (классическая — предложный падеж); в задании 8 такой случай ошибкой не считается.
- `вера в победу, уверенность в победе`; `удивляться стойкости`; `препятствовать развитию`.
- Прочие случаи проверяй по словарю управления (Грамота.ру, раздел «Проверка слова»).

## Согласование определений и приложений

- `два новых дома` (определение во мн. ч. при парных числительных); `два первых урока`.
- Географическое название в кавычках согласуется с родовым словом: `в городе Москве, на реке Оке`; названия станций метро не склоняются (`у станции «Тёплый Стан»`).

## Как решать задание 8 (процедура)

1. Прочитай список типов ошибок задания (он может отличаться в формулировках — сверяйся с демоверсией).
2. В каждом предложении ищи маркер из таблицы, а не «общее ощущение».
3. Помни: в списке из 5 предложений бывает «лишнее» предложение без ошибки или с ошибкой, не входящей в типы, — сопоставляй методом исключения, начиная с самого очевидного маркера.
